# Future Projects

The current hexapod robot is a proof-of-concept during Spring Quarter 2025 to test
if we're able to achieve hard-coded walking and human interaction.

The hard-coded walking uses [the pre-coded Python walking algorithms from the
manufacturer](), which support two gaits. It does not incorporate any feedback
to tell if the robot has encountered an obstacle, or is on uneven ground, or
has flipped over.

We are collecting stretch goals here for Summer 2025 and future quarters.
